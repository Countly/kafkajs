title: Pre-releases
---

This fork does not use pre-release channels (no `@beta`/`@next` npm tags, no automatic pre-release publishing on merge to master).

The release process is described in [`RELEASING.md`](../RELEASING.md) at the repo root.

Internal alpha tags (e.g. `3.0.0-alpha.N`) used during development of this fork are not published to npm.
